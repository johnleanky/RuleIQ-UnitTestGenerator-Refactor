The Author adapter consumes the unchanged full GeneratorRunReport schema, rejects visible contradictions and wrong known handoff identities without fetching candidate bytes or claiming independent proof of Validator OK, and emits only the existing two-field external object; Completed and PartiallyCompleted map to Completed, Failed maps to the fixed generation error, malformed response to the fixed invalid-response error.

Every ordinary projection passes the existing bidirectional source/full-schema audit before optional deliberate candidate corruption. Fault injection is explicit and precedes storage of that immutable candidate version; a corrupted candidate is never described as source-audit-verified. Validator inspects the actual stored version and generates its real report. Generator prunes/remaps or reconstructs from unchanged source using that report; every final surviving successful candidate receives a fresh full source/schema audit. UUID/address faults exercise named failure envelopes and exact caller intent; a malicious backend returning undetectably substituted payloads is not proven safe by a UUID-less response contract.
