P: How params pass from caller to invoked Model.
M: APPLY_MODEL -> Hybrid explicit+inheritance via pyParameters + pyPassCurrentParameterPage.
A: For each param used/defined in invoked model: 1) if name exists in caller operation pyParameters, use that explicit pyParametersParamValue/type; 2) else if pyPassCurrentParameterPage==true, inherit from caller Param page; 3) else value is empty/null in invoked model.
I: Explicit params override inherited params.

KT.15|M|ParameterNamespace
P: How params/properties/pages are referenced.
M: Param.PropertyName -> Param page property; namespace "Param.".
M: PropertyName without prefix -> named page or current page property; namespace none.
M: .PropertyName -> current page context property; namespace ".".

KT.17|L/A|ConditionalOperationTypes
P: Operations with conditional branches affecting execution.
M: Rule-Obj-Model -> ["WHEN","OTHERWISE"]. Condition field for WHEN -> KT.25/pyCondition. OTHERWISE condition is implicit: previous WHEN false.
S: Child operations execute only when branch condition is satisfied.
A: Conditional protocol: 1) extract condition via KT.25; 2) identify params/properties referenced; 3) resolve each via parameter/property trace; 4) evaluate true/false; 5) document "Step X condition: expr -> TRUE/FALSE" and child operations EXECUTED/NOT EXECUTED; 6) update property trace only for executed children.
X: Param.InputTempPage5="" passed explicitly; condition Param.InputTempPage5!='' -> false; WHEN children skipped.

KT.18|L|ContextSwitchOperations
P: Operations changing current, target, or source page context.
M: Rule-Obj-Model -> ["UPDATE_PAGE","FOR_EACH_PAGE_IN"]. Target page/list field -> pyPropertiesName.
S: FOR_EACH_PAGE_IN resolves each indexed item as current for its child scope; source behavior is defined by KT.34.
S: UPDATE_PAGE resolves pyPropertiesName as target/current for its child scope; source behavior is defined by KT.28.
Rules: .PropertyName -> context resolved by KT.23; Primary.PropertyName -> rule execution page and never changes; Top.PropertyName -> top-level page of current embedded branch.
X: UPDATE_PAGE TempPage4.pxResults(4); child SET .Comments writes TempPage4.pxResults(4).Comments; child SET Primary.Comments writes execution page Comments.
X: FOR_EACH_PAGE_IN TempPage4.pxResults; child .Comments resolves per element: TempPage4.pxResults(1).Comments, (2).Comments, etc.
R: KT.23,KT.28,KT.34.

KT.22|S/A|ModificationSemantics
P: How each modification operation affects values.
M: SET -> OVERWRITE: evaluate expression, replace target with result.
M: APPEND -> LIST_APPEND: add element to end of page list.
M: APPEND_AND_MAP_TO -> LIST_APPEND: adds element; in WHEN/OTHERWISE/OTHERWISE-WHEN branches, both may execute across iterations, so size equals executed branches, not matched conditions.
SET rules: expression evaluated first, then target overwritten. If expression does not read current target, previous target value is lost. If expression reads current target, result can preserve/append via expression, then overwrite.
X1: SET .Comments = Param.Comments + ", suffix"; Param.Comments="text" -> .Comments="text, suffix"; current .Comments ignored.
X2: SET .Comments = .Comments + ", suffix"; current .Comments="existing" -> .Comments="existing, suffix".
X3: SET Primary.Comments = .Comments + ", copied to Primary" overwrites Primary.Comments with current-context .Comments plus suffix; previous Primary.Comments ignored.
Forbidden assumptions: empty param does not skip SET; SET does not append unless expression reads current value; empty param does not mean target unchanged.
Mandatory tracing for every SET: extract expression via KT.21; identify refs; resolve refs; evaluate complete expression; document result; apply OVERWRITE.

KT.23|M|ContextResolutionRules
P: Resolve property refs in page contexts.
M: Relative write target .PropertyName -> current/target page.
M: Relative value reference .PropertyName -> active source when present; otherwise current/target.
M: Primary.PropertyName -> rule execution page; never changes with context switches.
M: Top.PropertyName -> top-level/root page of current branch; context-sensitive.
M: PageName.PropertyName -> explicit page reference.
M: UPDATE_PAGE BLANK sets target/current from pyPropertiesName and preserves inherited source.
M: UPDATE_PAGE WITH_VALUES_FROM sets target/current from pyPropertiesName and source from pyPropertiesValue.
I: Resolve UPDATE_PAGE source through KT.28 and inherited loop source through KT.34 before evaluating child expressions.
R: KT.18,KT.28,KT.34.

KT.24|S|PageCreationOperations
P: Page auto-creation and page assignment semantics.
M: UPDATE_PAGE -> auto-creates target page before child operations execute.
M: SET page assignment -> auto-creates target page only when target is not a PAGE parameter.
I: UPDATE_PAGE creates target as empty shell only. It does not copy/init child properties, lists, or groups. Target property exists only if a child write operation explicitly writes it.
Page assignment: If target is PAGE parameter (detect via KT.19+KT.13+KT.14), semantic=REFERENCE; target param and source page point to same object. If target is not PAGE parameter, semantic=COPY; target page is created/overwritten with copied properties from source page.
Core tracing: UPDATE_PAGE changes context and may auto-create target page. SET PageA=PageB is reference-only for PAGE params, copy otherwise. Never infer PAGE status from assignment text; verify formal parameter definition.

KT.26|L/S|ErrorHandlingOperations
P: Operations/functions that add or check error messages.
M: Rule-Obj-Model -> SET expression containing @pxAddMessageToProperty(MessageText,PropertyRef). Message extraction -> first parameter only.
Syntax: @pxAddMessageToProperty("message text","property reference").
I: For assertions, extract only MessageText. Do not include property name/prefix in pyExpectedValue because property context is already in pyPropertyName/pyPropertyAbsolutePath.
X: pyPropertiesValue:"@pxAddMessageToProperty(\"Sample error\",\".DocumentType\")" -> message text "Sample error", target .DocumentType. Correct expected value: "Sample error". Wrong: ".DocumentType: Sample error".
Comparators: has errors -> no pyExpectedValue; has no errors -> no pyExpectedValue; has error with message -> exact message text; has error message that contains -> substring only.

KT.27|L/S|ListOperations
P: List operation semantics.
M: APPEND -> ADD_TO_END; new index=current_size+1.
M: PREPEND -> ADD_TO_BEGINNING; new index=1; existing elements shift up.
M: INSERT -> ADD_AT_POSITION; specified index; subsequent elements shift up.
M: REMOVE -> DELETE_PAGE; removes entire page or list element.
M: SORT -> REORDER_LIST using sort criteria.
X: initial TempPage4.pxResults has 3 elements. APPEND -> creates (4). PREPEND -> new (1), old (1)(2)(3) become (2)(3)(4). INSERT at 2 -> new (2), old (2)(3) become (3)(4). SORT by .Comments ASC -> order changes by Comments.
Testing requirements: document before-state size/positions; apply semantic; verify list size, positions, new element index, shifted/preserved elements, and ordering when relevant. Assertions: ResultCount for list count; List assertion for individual element properties; ordering assertions when relevant.
I: Pega list indices are 1-based. APPEND=end. PREPEND=beginning. INSERT=specific position.
R: KT.36 for ResultCount existence gate.

KT.28|F/S|UpdatePageRelationship
P: Field specifying UPDATE_PAGE relationship type.
M: Rule-Obj-Model UPDATE_PAGE -> pyRelationNameUpdatepage values: "BLANK","WITH_VALUES_FROM".
BLANK: sets target/current from pyPropertiesName and preserves inherited source.
WITH_VALUES_FROM: sets target/current from pyPropertiesName and replaces source with pyPropertiesValue for the child scope.
S: Child write targets resolve against target/current; relative child value refs resolve against active source when present, otherwise target/current.
X BLANK: UPDATE_PAGE pyPropertiesName:"TempPage4.pxResults(4)", pyRelationNameUpdatepage:"BLANK"; child SET .Comments="text" -> TempPage4.pxResults(4).Comments="text".
X WITH_VALUES_FROM: UPDATE_PAGE pyPropertiesName:"TempPage2", pyRelationNameUpdatepage:"WITH_VALUES_FROM", pyPropertiesValue:"TempPage"; child SET .pyText=.pyText -> left TempPage2.pyText, right TempPage.pyText; copies source to target.
X inherited source: FOR_EACH_PAGE_IN .Items with pyUpdateSourceContext:true; nested UPDATE_PAGE .Target with BLANK; child SET .A=.B writes Primary.Target.A from Primary.Items(i).B.
I: Resolve inherited source through KT.34 before applying BLANK; WITH_VALUES_FROM replaces source within its child scope.
R: KT.18,KT.23,KT.34.
  
KT.28.S2|S|UpdatePageSeedPlacementRule
P: Seed placement for UPDATE_PAGE BLANK child value refs.
M: Write-target = pyPropertiesName. Source = inherited (ROOT unless overridden by WITH_VALUES_FROM or pyUpdateSourceContext=true).
I: BLANK does not change source. Child value refs (.X) resolve from source; child write targets (.X) resolve from write-target. These are different pages when BLANK is used.
A: Seed input properties on SOURCE page. Do not seed them on write-target page. Write-target needs no pre-seeding; UPDATE_PAGE auto-creates it (KT.24).
X: UPDATE_PAGE .Target BLANK; child SET .Out=.In. Source=Primary. Seed .In on Primary, not on .Target.
R: KT.23,KT.24,KT.28.

KT.36|A|ListPropertyExistenceGate
P: Choose correct assertion type for list property before emitting ResultCount.
A: Before every ResultCount assertion ask: did any write operation targeting this list execute on this scenario path? Write ops: APPEND,APPEND_AND_MAP_TO,INSERT,PREPEND,SET. If yes -> ResultCount allowed. If no -> assert Not exists; stop.
I: A list never written does not exist; it is not an empty list. ResultCount=0 is forbidden when no write reached the list on this path. Unreachable writes include operations skipped by EXIT_MODEL, false WHEN branch, or any early-termination mechanism.
R: KT.17,KT.27,KT.35.
